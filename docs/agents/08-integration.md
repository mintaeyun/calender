# 08. integration — 통합 (대시보드 · 설정 · 검색 · 내보내기 · PWA)

> 먼저 `00-overview.md`를 읽는다. 02~07이 대부분 끝나갈 때 시작하는 **마지막 세션**(웨이브 3). 일부(대시보드 틀, 설정 틀)는 계약 이후 미리 시작할 수 있다.

## 목표
각 영역 세션이 만든 api·컴포넌트를 모아 대시보드, 설정 통합 화면, 통합 검색, 내보내기/가져오기를 완성하고, 다크모드·PWA·접근성·성능을 점검해 마무리한다. 새 도메인 로직을 만들지 않고 **조립과 품질**에 집중한다.

## 선행 조건 / 의존
- 01: 라우트 껍데기, 레이아웃, `QuickAddProvider`, `useProfile()`.
- 02/03/04: 대시보드·검색·내보내기용 api(`listEvents`, `listTodos`, `getSummary`, `search*`), 빠른 추가 컴포넌트(`ev`/`todo`/`tx`).
- 05: `WeatherBadge`, `HourlyForecast`, `WeatherSettings`, `NotificationSettings`, 알림함, `useUnreadCount`.
- 06: `McpSettings`. 07: `GoogleSettings`.
- 의존 컴포넌트가 아직 없으면 목업 컴포넌트로 먼저 조립하고 나중에 교체한다(교체 지점에 `TODO(session-0X)` 주석).

### A. 대시보드 (P0)
- [ ] 목업 `Dashboard.tsx` 이식·실데이터 연결 (`/`):
  - 인사말(시간대별 "좋은 아침/오후/저녁") + 날짜(한국어 요일), 날씨 칩(`WeatherBadge`) — DASH-4
  - 이번 달 지출 큰 숫자 + 전월 대비 증감 + 남은 예산·잔액, 카테고리 구성 바(예산 80% 알림선 포함) — DASH-3
  - 오늘의 일정 카드: 지난 일정은 흐리게, **다음 일정 강조**(남은 시간 "1시간 20분 후", 장소) — DASH-1
  - 오늘의 할일: 체크로 즉시 완료(낙관적), "N / M" 완료 수, 기한초과 표시 — DASH-2
  - 최근 거래 5건, "전체 →" 링크
  - 빠른 추가 3버튼 → `QuickAddProvider.openQuick('tx'|'ev'|'todo')` — DASH-5
- [ ] 데이터는 각 영역 api/훅을 호출하고 한 화면에서 병렬 로딩. 위젯별 스켈레톤·오류 상태(하나 실패해도 나머지 표시). LCP 2.5초 목표(서버 컴포넌트 또는 prefetch 활용).
- [ ] 이번 주 일정 밀도 히트맵(목업): 이번 주 일정을 시간대×요일로 집계하는 `features/dashboard/lib/density.ts`(순수+테스트). 작업 시간대(09~21)만. "빈 시간 찾기" 링크는 P2.
- [ ] 이번 주 업무 요약 접이식(목업 하단): 업무 분류 일정 건수·시간, 할일 완료/전체, 기한초과, 다음 마감, 요일별 카드. "Claude 요약" 문구는 정적 텍스트로 만들지 말고, 데이터에서 규칙 기반으로 생성(예: 가장 일정이 몰린 요일). LLM 호출은 하지 않는다. 이 위젯은 P1~P2 후순위.
- [ ] DASH-6 (P2): 주간 할일 달성률, 지출 TOP3 위젯.

### B. 설정 통합 화면 (P0)
- [ ] `/settings/[tab]` 7개 탭 레이아웃(목업 `Settings.tsx` 이식). 탭: 프로필·화면 / 카테고리·태그 / 알림 / Google 캘린더 / 날씨 / MCP 연결 / 백업·내보내기. 각 탭은 해당 세션의 컴포넌트를 마운트: `NotificationSettings`(05), `GoogleSettings`(07), `WeatherSettings`(05), `McpSettings`(06). 탭 우측 태그(연결됨, 토큰 개수)는 실제 상태.
- [ ] **프로필·화면(SET-1)**: 이름, 이메일(읽기 전용, 로그인 방식 표시), 시간대(IANA 목록 검색), 테마(라이트/다크/시스템), 주 시작 요일(월/일), 기본 시작 화면. `profiles` update, 변경 즉시 앱 전체 반영(`useProfile()` invalidate). 비밀번호 변경·로그아웃·계정 삭제(01의 AUTH-3 기능 호출, 계정 삭제는 2단계 확인).
- [ ] **카테고리·태그(SET-2)**: 가계부 지출/수입 카테고리, 일정 분류(`calendars`), 할일 프로젝트·태그를 한 화면에서 관리. 04/03의 api를 호출(직접 DB 접근 금지). 거래가 있는 카테고리 삭제 시 "보관됩니다" 안내. 색상 선택기(팔레트).
- [ ] 빈/오류/로딩 상태를 모든 탭에서 처리.

### C. 테마·다크모드 (P1)
- [ ] 라이트/다크/시스템. 01이 만든 색 토큰 CSS 변수에 라이트 값 정의, `data-theme` 속성 + `prefers-color-scheme`. 깜빡임 방지용 초기 스크립트. 색상 대비 WCAG AA 확인(특히 라임 `oklch(0.9 0.19 125)` 위 텍스트).
- [ ] 목업 전체가 다크 고정 색(`#1a1a1d` 등 하드코딩)을 쓰므로, 각 영역 컴포넌트의 하드코딩 색을 토큰으로 바꾸는 요청을 `REQUESTS.md`로 각 세션에 보내거나, 영역 세션이 끝난 뒤 이 세션이 일괄 치환한다(소유권 이전을 사용자에게 확인).

### D. 통합 검색 (P2, SRCH-1)
- [ ] `/search?q=`: 헤더 검색에서 진입. 일정·할일·거래를 병렬 검색(02/03/04의 `search*` api 사용) 후 유형별 그룹(목업)과 탭(전체/일정/할일/거래, 건수). 결과 클릭 시 해당 화면·항목으로 이동. 디바운스, 빈 결과 문구, 최근 검색(localStorage).
- [ ] 거래 금액 검색(예: "12000")과 메모 검색을 모두 지원할지 여부는 04와 협의.

### E. 내보내기·가져오기 (P2, SET-3)
- [ ] 일정/할일/거래 CSV 내보내기(UTF-8 BOM으로 Excel 한글 깨짐 방지), Excel(xlsx)은 라이브러리(`exceljs` 또는 `xlsx`) 사용. 기간 선택, 대용량은 페이지 단위 스트리밍.
- [ ] 거래 CSV 가져오기: 컬럼 매핑 미리보기 → 검증(금액 양의 정수·날짜 형식·카테고리/계좌 이름 매칭, 매칭 실패 행 보고) → 확정 후 일괄 insert(트랜잭션, 실패 시 전부 롤백). 중복 감지(같은 날짜·금액·메모) 경고. 가져오기 로직은 04 api의 `createTransaction` 규칙(금액 검증)을 재사용.
- [ ] 개인 데이터이므로 내보내기 파일에 서버 저장 없이 브라우저에서 생성.

### F. PWA·품질 (P2)
- [ ] 매니페스트(이름 "라이프 매니저", 아이콘, 테마색), 서비스 워커(05의 푸시와 **하나의 SW로 통합**: 05와 조율), 설치 가능성 확인, 오프라인 폴백 페이지.
- [ ] 접근성: 키보드 조작(탭 순서, 모달 포커스 트랩, Esc 닫기), 클릭 가능한 `span`/`div`를 버튼 요소로 교체(목업은 div onClick), 색 외 아이콘/텍스트 병행, `aria-*` 라벨.
- [ ] 반응형: ≥360px 모바일 레이아웃. 목업은 데스크톱 고정폭(그리드 3단 등)이므로 각 화면 모바일 변형 필요(하단 탭 또는 햄버거 내비). 영역 세션이 데스크톱을 끝낸 뒤 일괄 점검.
- [ ] 성능: LCP 2.5초, 월 전환 300ms 점검(Lighthouse), 번들 크기 확인, 이미지/폰트 최적화.
- [ ] 정리: `web/src/lib/data.ts`(목업 샘플)와 `web/src/components/screens/`(이식 완료된 목업)를 삭제하고 사용처가 없는지 `tsc`로 확인.
- [ ] `README.md` 작성(개요, 설치, 환경변수, 실행, 배포(Vercel+Supabase), MCP 커넥터 문서 링크), `AGENTS.md` 최종 갱신.

## 제공하는 계약

## 지켜야 할 규칙 · 함정
- 새 DB 접근 코드를 이 세션에서 직접 쓰지 않는다. 영역 api를 호출하고, 부족하면 `REQUESTS.md`로 해당 세션에 요청한다(또는 해당 세션이 끝났다면 사용자 승인 후 직접 추가).
- 대시보드는 여러 위젯이 병렬 로딩되므로 한 위젯 오류가 전체를 막지 않게 한다.
- 시간·날짜는 사용자 TZ 기준(오늘/이번 주/이번 달). 월·주 경계 계산이 서버/클라이언트에서 다르지 않게 `lib/time.ts` 사용.
- 내보내기·검색 결과에 소프트 삭제 항목을 포함하지 않는다.
- 계정 삭제는 되돌릴 수 없으므로 2단계 확인과 안내 문구 필수.
